// Key Achievements

Seeding the landing pages with CCLD data

I scraped and downloaded records from the Community Care Licensing Division (CCLD) to fill the Next.js landing pages with facility information, so each page had real licensing details for the care homes it listed.

CCLD data changes often, so a one-time download would have gone stale. I wrote scripts in Next.js and Ruby on Rails that extract the structured records and rerun on a schedule, which keeps the pages current.

Conversion experiments

The pages were built with Next.js, Material UI and Storybook. Next.js handled rendering, Material UI kept the design consistent, and Storybook let us build and test custom components quickly.

The goal was more sign-ups without more ad spend. We ran A/B tests on the landing pages, read the behaviour data to see which elements people responded to, and kept the variants that moved sign-ups.

SEO

Next.js let us choose between client-side and server-side rendering page by page. Pages with frequent updates or personalized content render on the client. Static, content-heavy pages render on the server so search engines can index them. Code splitting kept the JavaScript small, which helped page load times and mobile responsiveness.

The programmatic SEO work started with keyword research. From there we added schema markup and structured data to the pages, scripted sitemap generation and structured data output, and added custom tracking events so we could see what the pages were doing. Custom dashboards showed SEO performance, and we passed what we learned to the rest of the development team.
