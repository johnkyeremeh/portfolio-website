// My Contributions

  • Built and maintained the system that linked patients to doctors on Ruby on Rails, Tailwind CSS, and Heroku. Patient engagement and satisfaction rose 50%.
  • Worked with developers and product managers to add new features to the app.
  • Wrote automated test suites in RSpec, which cut bugs 40% and raised code maintainability 25%.
  • Fixed bugs across the front end, back end, and database, and improved the app's performance and stability.
  • Ran QA testing against customer and regulatory requirements, which cut customer-reported issues 70%.
  • Built the admin panel with Administrate, a Rails admin engine.

// Security Measures

  • Used Rails' built-in XSS protection, escaping and sanitizing user-generated content before it renders in views.
  • Used Rails' built-in CSRF protection, with a unique token per form validated on submission.
  • Used Devise for user authentication.
  • Validated user input on the client and the server to prevent SQL injection.
  • Hashed passwords with bcrypt, following Rails conventions.
  • Configured Rails session management with secure cookies and expiration settings.
  • Ran security audits with tools like Brakeman and bundler-audit to catch problems in gems and code.
  • Kept gems and Rails up to date to avoid known vulnerabilities.

// Amazon S3 for Photo and Data Storage

Photos and data are stored on Amazon S3:

  • Used the aws-sdk gem to talk to S3 from the Rails app.
  • Wrote the models and functions that upload profile pictures to S3 and retrieve them.
  • Used S3 access controls so users can only read and change their own data.
  • Turned on versioning and lifecycle policies to manage retention and cost.
