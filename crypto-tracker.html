Project Details

I wanted to build a responsive web app that shows live data for the top 10 cryptocurrencies from the CoinMarketCap API.

Web Stack and Explanation

Backend
For the backend, I chose to use Express to fetch data from the CoinMarketCap API. I also used Axios for the HTTP requests. The backend was implemented in a separate folder named "backend" inside the root folder of the project.
Frontend
The frontend is a Create React App project styled with Bootstrap for responsive components.

Problems and Thought Process

Keeping the data current was the first problem. The frontend uses setInterval to poll the backend every 5 minutes, and the backend fetches fresh data from the CoinMarketCap API. The API also returns far more than the page needs, so I pull out the fields for each cryptocurrency and render them with React components.
