// How I work

Find the leak.
Ship the fix.
Prove it worked.

Nine years of growth work taught me the same lesson repeatedly: the winning experiment is usually boring, and the expensive part is arguing about it for a quarter. So I work in short cycles, I name the metric before I build, and I let the result end the debate.

W1
Diagnose
Pull the funnel apart and find where the drop-off actually is. Interview the users who left. One week, no redesigns, no opinions yet.
W2
Model & size
Put a number on the opportunity and pick the single metric the work has to move. If it isn't worth the engineering time, we don't build it.
W3
Ship the experiment
Copy, flow, landing page, instrumentation. Built and shipped, usually by me, behind a clean A/B test with the sample size agreed up front.
W4
Read the result, then repeat
Winners get scaled and written down. Losers get documented just as carefully, because the fastest way to lose a quarter is repeating a loss.
